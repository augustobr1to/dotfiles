# Contributing to dotfiles

Thanks for your interest in contributing. Contributions are welcome and appreciated.

How to contribute

- Fork the repository and create a feature branch: `git checkout -b my-feature`
- Make small, focused changes and include tests or verification steps where relevant.
- Commit with clear messages and open a pull request against `main`.

Code style and reviews

- Keep changes minimal and well-explained in PR descriptions.
- If you change shell or editor configs, include reproduction and manual test instructions.

Maintainer notes

- Major changes (tooling or layout) should be discussed in an issue first.
- The maintainer may request revisions before merging.
